API & Интеграция с другим сайтом
Открытый доступ без CORS ограничений

Ты можешь отправлять запросы к этому сайту с любого другого проекта (React, Vue, Node.js, Python, PHP, Vanilla JS). На сервере включён CORS (Access-Control-Allow-Origin: *).

1. Поиск каналов: POST /api/search

// JavaScript на твоём сайте:
const res = await fetch('https://' + window.location.host + '/api/search', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query: 'крипта', type: 'channel' })
});
const data = await res.json();
console.log(data.results); // Список найденных каналов

2. Парсер постов канала: GET /api/posts?handle={name}

// Получить свежие посты канала в JSON:
const res = await fetch('https://' + window.location.host + '/api/posts?handle=durov');
const data = await res.json();
console.log(data.posts); // Массив постов (текст, дата, просмотры, ссылки)
