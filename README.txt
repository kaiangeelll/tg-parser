Поиск Telegram — папка проекта

Запуск:
1. Дважды щёлкни start.bat.
2. Открой http://127.0.0.1:8765
3. Оставь окно запуска открытым, пока пользуешься сайтом. Для остановки закрой его.

Нужен установленный Python 3. Сторонние библиотеки не нужны.

Поиск обращается к публичному каталогу TGFind через локальный сервер. Вход в Telegram, личный аккаунт и бот-токен не используются. Запросы поиска передаются TGFind. Каталог индексирует часть публичных каналов, поэтому найденные варианты не гарантируют полный список Telegram. Подписчики и описания могут быть неактуальными.

Файлы:
- index.html — страница сайта
- app.js — интерфейс и взаимодействие
- server.py — локальный сервер и соединение с каталогом
- start.bat — запуск
